## 🎄 Sobre o projeto

Uma aplicação web simples para organizar o sorteio de amigo secreto entre amigos,
família ou colegas de trabalho. Basta cadastrar os nomes e realizar o sorteio,
sem precisar de cadastro ou instalação.

## ✨ Funcionalidades

- ➕ Adicionar participantes à lista
- 🚫 Evitar nomes vazios ou repetidos
- 🎲 Sorteio aleatório do amigo secreto
- 📋 Exibição do resultado na tela
- 🔄 Opção de reiniciar e fazer um novo sorteio


## 🕹️ Como usar

1. Digite o nome de um participante e clique em **Adicionar**.
2. Repita o processo até incluir todo mundo (mínimo de 2 pessoas).
3. Clique em **Sortear amigo**.
4. Confira o resultado do sorteio!

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/Layaranobre/Sorteio-Amigos.git

# Entre na pasta
cd Sorteio-Amigos
```

Depois, é só abrir o arquivo `index.html` no navegador. Não precisa instalar nada!
